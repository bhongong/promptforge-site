About PromptForge

Proven prompts, forged to work.

What this is

PromptForge is a prompt library built around a working prompt-optimizer engine: each template is generated, then pushed through a multi-round critic loop — base draft, LLM polish, checklist evaluation against a target score, then improvement — and only ships once it clears the checklist.

The current library holds 32 templates across 14 categories and 16 formulas, plus a mastered Stable Diffusion 1.5 cinematic POV guide distilled from a 29 KB researched source document.

What this is not

  • It is not a scrape or a re-list of other people's prompts.
  • It is not a promise that a prompt works with every model — templates are written for mainstream LLMs and for SD1.5 specifically.
  • It is not the optimizer engine itself. The software stays internal; the products are the content it produced and the rubrics it used.

How the site is built

A static site generated from the same knowledge base that ships in the paid packs, so the free pages and the paid files can never drift apart. Every prompt is rendered into the HTML at build time — nothing here depends on a crawl-blocking client-side render.
